## Thermodynamic boundary closure

For every requested boundary pressure:

```text
p_b = prescribed pressure
T_sat,b = CoolProp T(P=p_b, Q=0)
T_b = T_sat,b - 5 K
rho_b = CoolProp Dmass(P=p_b, T=T_b)
e_b = CoolProp Umass(P=p_b, T=T_b)
```

The exact `rho_b/e_b` pair is then passed through the reviewed HEM phase
classifier, boundary-region derivation, equilibrium-quality/void-fraction
contract, equilibrium sound-speed estimator, pressure/temperature recovery
check, and strict `VerificationHEMLiquidOpenTwoPhaseEOS` accepted-state path.

The implementation does not add or call a pressure-only real-fluid density
inversion.  It also does not copy transported quality from the adjacent interior
cell into the prescribed boundary state.

## Ghost-state contract

For an allowed right-boundary outlet state with adjacent interior velocity
`u_i >= 0`:

```text
rho_g = rho_b
u_g   = u_i
e_g   = e_b
q_g   = q_eq(rho_b, e_b)

U_g = make_conserved(rho_g, u_g, e_g, q_g)
```

Every right ghost cell receives the same validated conservative state.  The
adapter verifies the resulting ghost through the supplied mixed accepted-state
EOS and does not modify internal cells.

For `u_i < 0`, the verification adapter applies the existing reflective right
boundary and increments an explicit reverse-flow fallback diagnostic.  The
prototype acceptance target remains zero reverse-flow fallbacks.

The adapter rejects invalid side selection, non-positive ghost count, invalid
array shape or dtype, non-finite adjacent state, non-positive adjacent density,
provider failure, and mixed-EOS rejection before partially writing ghost cells.
